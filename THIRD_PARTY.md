# Third-party components

Atlas uses the sponsor's products wherever their functionality covers a required feature.

| Component | Source | Role |
| --- | --- | --- |
| FalkorDB | https://github.com/FalkorDB/FalkorDB | Graph database and native search |
| FalkorDB Python client | https://github.com/FalkorDB/falkordb-py | Parameterized graph operations |
| Code-Graph 0.4.2 | https://github.com/FalkorDB/Code-Graph | MIT-licensed repository analysis dependency |
| GraphRAG SDK 1.4.0 | https://github.com/FalkorDB/GraphRAG-SDK | Apache-2.0 document ingestion and retrieval |
| FalkorDB Canvas 0.3.3 | https://github.com/FalkorDB/falkordb-canvas | Graph rendering |
| Graphiti 0.31.1 | https://github.com/getzep/graphiti | Apache-2.0 temporal episode memory; external integration recommended by FalkorDB |
| LiteLLM | https://github.com/BerriAI/litellm | Provider routing already supported by sponsor tooling |
| FastAPI / Starlette / Uvicorn | https://github.com/fastapi/fastapi | Application server |
| React / Vite / TypeScript | https://react.dev/ | Workspace interface |
| GitHub REST API | https://docs.github.com/en/rest/issues | Public issue/comment retrieval; no GitHub credentials required for current integration |
| Authlib | https://github.com/authlib/authlib | Google OAuth/OIDC |
| Cryptography | https://github.com/pyca/cryptography | Fernet encryption |
| Lucide | https://lucide.dev/ | ISC-licensed interface icons |
| React Markdown | https://github.com/remarkjs/react-markdown | Safe Markdown rendering without raw HTML |

Dependencies retain their upstream licences. Atlas does not claim ownership of these libraries or treat an integration-catalogue listing as sponsor ownership. Mem0, additional vector databases, and additional agent-orchestration frameworks are not used.

The interface uses DM Sans and Manrope through Google Fonts, with system-font fallbacks. These fonts are under the SIL Open Font License.
